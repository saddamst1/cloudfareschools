# SchoolsPedia — School Directory India

A comprehensive directory of over 16.5 Lakh+ schools across all 36 States & Union Territories in India.

## Cloudflare Pages Deployment
This project is configured for Cloudflare Pages using OpenNext.

### Build Settings
- **Build command**: `node node_modules/@opennextjs/cloudflare/dist/cli/index.js build`
- **Build output directory**: `.open-next/assets`
- **Node.js version**: `20`
